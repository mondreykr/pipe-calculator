# Pipe Wall Calculator — Development Handoff

**Prepared:** 18 August 2026
**Current build:** `plain-calculator-v9.html`
**Status:** Working prototype, correct math, unverified reference data. Not fit for use until the items in §6 are closed.

---

## 1. What this is

A single-page internal web tool that answers one question: **for a given pipe size and design condition, what schedule do I specify?**

It computes the minimum wall thickness required under ASME B31.3 para. 304.1.2 and lists the EnerCorp permitted schedules for that size, highlighting the lightest one that satisfies the requirement.

It replaces the manual step where an engineer runs the line-list formula by hand to answer a one-off question. It does **not** replace the line list, which remains the calculation of record.

### Deliberately out of scope

Branch reinforcement (304.3), external pressure and vacuum, thermal expansion and support loading, fatigue, Category M and severe cyclic service, flange and fitting ratings, MDMT. Also excluded: multi-line batch processing, cost output, saved sessions, and user accounts. Each of these was considered and rejected during specification — see `DECISIONS.md` before adding any of them back.

---

## 2. Current state

Single self-contained HTML file. No build step, no dependencies except the Inter webfont from Google Fonts. All logic is in one inline `<script>`.

**Inputs:** pipe size, design pressure, design temperature, material, corrosion allowance, joint efficiency, mill tolerance (with a custom-percentage option).

**Outputs:** minimum wall required, and the permitted schedule ladder with sub-minimum rows dimmed and the winning row highlighted.

**Layout:** inputs left, results right, footnotes below. Responsive down to a single column.

---

## 3. The engine

```
t          = P·D / (2·(S·E + Y·P))          pressure design thickness
minimum    = (t + c + q) / (1 − mill_tol)   minimum nominal wall to purchase
selection  = lightest permitted schedule whose wall ≥ minimum
```

Where `P` is design pressure (psig), `D` is outside diameter (in), `S` is allowable stress at design temperature (psi), `E` is joint efficiency, `Y` is 0.4, `c` is corrosion allowance (in), and `q` is thread or groove depth (currently fixed at zero).

This is algebraically identical to the line-list method, which computes available wall as `(nominal × 0.875) − CA − thread` and requires it to exceed `t`. Confirmed equivalent — see §5.

### Non-obvious implementation requirements

**The schedule ladder must be sorted by wall thickness, not by schedule name.** This is not cosmetic. From NPS 8 upward, XXS is thinner than Sch 160. From NPS 18 upward, XS is thinner than Sch 40. A name-ordered or insertion-ordered list selects heavier pipe than required. There should be a regression test for this.

**Stop conditions.** Two, both of which must suppress the schedule selection entirely rather than degrade it:
- `t ≥ D/6` — thin-wall formula no longer applies
- No permitted schedule satisfies the minimum

**Temperature guard.** Each material carries a maximum tabulated temperature. Above it, the tool must refuse rather than extrapolate. Below the lowest tabulated point the interpolation currently clamps to the lowest value; see §7.

## 4. Reference data

Three tables, all in the inline script, all needing different treatment.

### `PIPE` — dimensions and permitted schedules

Sourced from the EnerCorp schedule matrix. Sizes 1-1/4, 2-1/2, 3-1/2, 5 and 22 are excluded by that matrix. Where STD and Sch 40 are identical (up to NPS 10) or XS and Sch 80 are identical (up to NPS 8), only one designation is listed. NPS 14 and above have no XXS. NPS 16 has no Sch 40, since it equals XS.

Values are ASME B36.10M nominal. Five are independently confirmed against line list 268782: `8.625/Sch 80 = 0.500`, `10.75/Sch 80 = 0.594`, `4.5/Sch 160 = 0.531`, `2.375/Sch 160 = 0.344`, `1.315/XXS = 0.358`.

> **Note for whoever holds the source matrix:** it lists NPS 2 OD as 2.38. The correct value is 2.375, which is what line list 268782 uses. The rounding propagated into the ID column, which reads 2.072 where it should read 2.067. The calculator uses 2.375. The source table should be corrected.

### `MATS` — allowable stress

**Provisional. This is the only real blocker.** One value is confirmed: A333 Gr 6 at 500 °F = 19,000 psi, matching line list 268782. Everything else is placeholder and must be verified against ASME B31.3 2024 Table A-1 from a licensed copy.

Roughly fifteen values across three materials. Do not source these from public web calculators — Table A-1 is ASME copyright and those sites carry their own risk, which does not transfer.

Move this table into its own file, separate from the calculation logic, so it can be reviewed and revised without touching code.

### `CAS`, `JOINTS`, `TOLS`

Corrosion allowances 0 through 1/4″. Joint efficiency 1.00 / 0.90 / 0.80, matching the line-list rule that derives E from radiography coverage. Mill tolerance 12.5% default, 10% for API 5L, plus custom entry.

## 5. Verification performed

All six lines of line list 268782 were run through both methods. Conditions: A333 Gr 6, 660 psig, 500 °F, S = 19,000, E = 1.0, Y = 0.4, CA = 0.250″, mill tolerance 12.5%, thread depth 0.

Pressure design thickness `t` matched the line-list formula to five decimal places on every line.

| Line | NPS | t (in) | Minimum wall (in) | Tool selects | Engineer specified |
|---|---|---|---|---|---|
| 8-CLS-P-001 | 8 | 0.147750 | 0.4546 | Sch 80 | Sch 80 |
| 10-CLS-G-001 | 10 | 0.184152 | 0.4962 | Sch XS | Sch 80 |
| 8-CLS-G-001 | 8 | 0.147750 | 0.4546 | Sch 80 | Sch 80 |
| (1″ XXS) | 1 | 0.022526 | 0.3115 | Sch XXS | Sch XXS |
| 4-CSL-D-001 | 4 | 0.077087 | 0.3738 | Sch 160 | Sch 160 |
| 2-CSL-D-002 | 2 | 0.040685 | 0.3322 | Sch 160 | Sch 160 |

Five of six selections match exactly. The 10″ line differs because XS at 0.500″ clears a 0.4962″ requirement by 0.0038″ and the engineer went up one schedule — a margin judgment the calculation does not contain.

**Use this table as the seed regression fixture.** Add cases for the two sort traps (NPS 18 must place XS above Sch 40; NPS 8 must place XXS above Sch 160), both stop conditions, and the temperature guard.

## 7. Known issues and open decisions

**Three-decimal display can mislead.** The comparison runs at full precision, but a requirement of 0.5004″ renders as "0.500" beside a 0.500″ wall that fails it. Showing the required value to four decimals would remove the ambiguity.

**No margin indication.** A line passing by 0.0038″ looks identical to one passing by 0.15″. Margin was deliberately removed as visual noise, but line 10-CLS-G-001 is exactly the case where an engineer would want it. Reconsider — possibly as a plain figure rather than a colour treatment.

**No job reference or version stamp.** Results will be screenshotted into emails. Without a build version and a job or line number, there is no way to tell which build produced a given result or what it was for.

**Temperature below the tabulated range clamps** to the lowest value rather than refusing. Conservative for carbon steel, but it should be a deliberate decision given the −50 °F MDMT on this equipment.

**Thread and groove depth is fixed at zero.** Correct for welded and flanged construction. If threaded connections ever appear, the input must return.

**Y is fixed at 0.4.** Valid for ferritic materials below 900 °F. The material temperature ceilings currently keep every path inside that range, but the coupling is implicit rather than enforced.

## 8. Design decisions to preserve

These were settled after building and rejecting alternatives. Reversing any of them should be a conscious choice, not a refactor side effect.

- **The ladder, not a single answer.** Showing every permitted schedule with the minimum highlighted is what lets an engineer see that XS passes and still choose Sch 80. A single-answer output hides the options.
- **Selection, not verification.** The tool picks the schedule from the requirement. The line list does the reverse. Both are useful; this one is not a second line list.
- **No interpretation layer.** Earlier versions stated verdicts in prose, colour-coded margin, and compared pipe capacity against flange rating. All were rejected as noise or as answering a different question. See `DECISIONS.md`.
- **Refusal is a result.** Out-of-range conditions produce a plain statement and no number. Never a partial answer — partial answers get screenshotted.
